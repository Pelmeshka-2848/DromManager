# Safety Policy

## Core principles

- DromManager is an assistant overlay, not a bypass bot.
- No automatic message sending without explicit user confirmation.
- No bypass of login, captcha, anti-spam, or platform restrictions.

## Safe mode (default)

- Extension only prepares and inserts text drafts.
- User reviews content and sends manually in Drom UI.
- Any future semi-automation must remain opt-in and auditable.
